## Цель проекта

Цель проекта — разработать **учебный компьютерный алгебраический набор DMC**, предназначенный для демонстрации и отработки алгоритмов работы с различными типами чисел и алгебраическими объектами в курсе ДМиТИ.

Основные задачи проекта:

- реализовать модульную библиотеку для работы с базовыми алгебраическими сущностями (натуральные, целые, рациональные числа, полиномы и т.п.);
- предоставить удобный интерфейс (через `main.py`) для запуска и тестирования реализованных алгоритмов;
- покрыть ключевые операции автотестами (в репозитории уже есть тесты для операций с рациональными числами и вычитания).

> Примечание: точный набор модулей и операций определяется формулировкой задания и может расширяться по мере развития проекта.

## Структура проекта

Структура репозитория на данный момент:

- `src/` — исходный код ядра DMC:
  - реализация основных структур данных и алгоритмов;
  - модули для работы с различными типами чисел и алгебраическими объектами.
- `tests/` — модульные и интеграционные тесты:
  - тестовые сценарии для отдельных операций и модулей;
  - используется формат `test_*.py`, совместимый с `pytest`.
- `docs/` — документация:
  - описания модулей;
  - заметки по архитектуре;
  - материалы по коллоквиуму.
- `tools/` — служебные скрипты и утилиты:
  - вспомогательные инструменты для разработки, запуска, анализа.
- `Workspace/` — рабочее пространство:
  - черновики, временные файлы, прототипы.

Файлы в корне репозитория:

- `main.py` — точка входа для запуска учебного набора DMC.
- `README.md` — текущий файл с описанием проекта.
- `pyproject.toml` — конфигурация проекта для сборки/установки.
- `registry.json` — реестр/конфигурация доступных операций и/или модулей (структура определяется реализацией).
- `requirements.txt` — список внешних зависимостей проекта.
- `test_rational_input.py`, `test_rational_red.py`, `test_rational_sub.py`,
  `test_sub_debug.py`, `test_sub_fixed.py`, `test_sub_full.py` —
  отдельные тестовые модули для проверки операций над рациональными числами и вычитания.

## Инструменты

В проекте используются:

- **Язык программирования:** Python 3.x  
  (рекомендуется актуальная версия Python 3, под которую ведётся разработка).
- **Среда разработки:** любая удобная IDE / редактор (PyCharm, VS Code и т.д.).
- **Система тестирования:** формат тестовых файлов `test_*.py`, совместимый с `pytest`.  
  При наличии `pytest` можно запускать тесты командой `pytest` в корне проекта.

При необходимости этот раздел можно дополнить точным списком библиотек из `requirements.txt` 
(например, `pytest`, средства логирования, парсинга аргументов командной строки и т.п.).

## Ход выполнения работы

1. **Проектирование структуры модулей**
   - Определение набора поддерживаемых типов данных (натуральные, целые, рациональные числа, полиномы и др.).
   - Проектирование интерфейсов модулей в `src/` (структуры данных, базовые операции).

2. **Реализация базовых операций**
   - Реализация независимых операций (инициализация, сравнение, базовая арифметика).
   - Создание первых тестов в `tests/` и в отдельных `test_*.py` в корне репозитория
     (например, тесты для операций над рациональными числами и вычитания).

3. **Расширение функциональности**
   - Добавление более сложных операций, зависящих от уже реализованных модулей.
   - При необходимости — рефакторинг структуры `src/` для улучшения читаемости и переиспользования кода.

4. **Интерфейс взаимодействия**
   - Настройка сценариев запуска через `main.py`:
     - выбор режима работы (например, интерактивный режим, запуск заранее подготовленных сценариев);
     - вывод результатов вычислений в удобном для пользователя формате.

5. **Тестирование и отладка**
   - Регулярный запуск тестов (`pytest` или аналогичный инструмент).
   - Добавление новых тестов при реализации каждой новой операции.
   - Поддержка актуальности `registry.json` и других конфигурационных файлов.

## Как запустить проект

Ниже приведён базовый сценарий запуска под **Windows**.  
Команды для Linux/macOS отличаются только активацией виртуального окружения.

1. **Клонировать репозиторий**

   ```bash
   git clone https://github.com/krasnikdanil/DMC.git
   cd DMC
   ```

2. **Создать виртуальное окружение**

   ```bash
   python -m venv venv
   ```

3. **Активировать виртуальное окружение**

   ```bash
   venv\Scripts ctivate
   ```

4. **Установить зависимости**

   ```bash
   pip install -r requirements.txt
   ```

5. **Запустить основной модуль**

   ```bash
   python main.py
   ```

   > Конкретное поведение `main.py` (режимы работы, доступные команды) зависит от реализации
   > и может быть дополнительно описано в документации в каталоге `docs/`.

6. **(Опционально) Запуск тестов**

   При установленном `pytest`:

   ```bash
   pytest
   ```

   или для запуска только отдельных тестовых файлов:

   ```bash
   pytest test_rational_input.py
   pytest test_rational_red.py
   pytest test_rational_sub.py
   ```
